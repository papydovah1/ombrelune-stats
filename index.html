⚙️ Configuration Discord & Règles de Calcul

1️⃣ Lien ou ID du salon Discord

Dans Discord, fais un Clic droit sur le salon d'annonces puis clique sur « Copier le lien » (ou copie directement l'adresse `https://discord.com/channels/.../...` depuis ton navigateur) et colle-la ci-dessous.

2️⃣ Récupérer ton Token Discord (en 10 secondes)

  1. Ouvre Discord dans ton navigateur (ou fais Ctrl+Shift+I sur l'application Discord PC).
  2. Va dans l'onglet Réseau (Network) en haut des outils de développement.
  3. Tape /api dans le petit filtre, puis clique sur n'importe quel salon dans Discord.
  4. Clique sur une ligne (ex: messages ou science), descends dans En-têtes de requête (Request Headers) et copie la valeur de authorization.
